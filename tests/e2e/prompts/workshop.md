Use the aidlc-discovery skill to run a complete Discovery workshop in unattended mode, as configured in config.md in this folder.

The scenario is in README.md in this folder: take the product, the people in the room, the business metric with its baseline, and the candidate use cases from it. Run all five phases in order (Signals, Working Backwards, Prototype, Validate, Handoff) on the data configured in config.md. There is no product codebase in this folder, so skip the current-product map. Do not stop to ask questions or confirm checkpoints. Finish with the Handoff, and do not start AI-DLC.
