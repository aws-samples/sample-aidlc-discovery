# Train the trainer: chat script for the 2-hour remote session

The messages to post in the call's chat, in order, ready to copy. Times follow "The 2-hour remote version" in `train-the-trainer.md`. Replace the parts in [brackets].

## Before the call (the day before)

```
Tomorrow's AI-DLC Discovery train the trainer: pre-work, about 20 minutes. Please do it today, so we spend the session practising, not installing.

1. Unzip the pack I sent you: the facilitator pack if you facilitate, the trainee pack otherwise.
2. In AWS Quick Desktop: Customize > Skills > Create > From folder, and choose the aidlc-discovery folder from the pack.
3. Start a new chat and type: List my skills. Reply to this message with a screenshot. You should see AI-DLC Discovery Workshop.
4. Open the anycompany-air folder from the pack and read its README.md, the scenario page. Read nothing else; the answers are hidden in the data.
5. Open role-cards.html from the pack and find your card.
6. First facilitators: create a Space for your team (Spaces > Create space), name it after your team, copy the sample into it (the copy prompt in facilitator/dry-run-air.md, step 0), and share it with your team as Owners. Everyone: attach your team's Space to a new chat (the + menu > Spaces).

Your team and role:
[Team 1: facilitators [name] (first half) and [name] (second half). [Name]: head of digital. [Name]: engineering lead. [Name]: customer service operations lead. [Name]: head of corporate accounts.]
[Team 2: ...]
```

## 00:00 Main room

```
Welcome. Today you learn to facilitate an AI-DLC Discovery workshop by running one. The rule that matters most: the assistant drafts, the team decides. Your job as facilitator is the room: time, energy, and making sure the team does the thinking.
```

```
Breakout rules:
- One team per breakout. The first facilitator shares AWS Quick and follows dry-run-air.md (in the pack, facilitator folder).
- Everyone else plays their role card, in their own words. Push back when your character would.
- At 00:45 the second facilitator takes over the room. The first keeps sharing Quick and types what the second asks for.
- Post one line in this chat when your team finishes a phase, for example: "Team 2: Signals done, ops lead challenged."
- Debrief questions appear here. Answer them in a thread while Quick works.
```

## 00:10 Breakouts open

```
Breakouts are open. First facilitator: share Quick, run List my skills, then paste the start prompt from dry-run-air.md. Role players: introduce yourself in character, one line each.
```

## 00:15 Kickoff and Signals

```
Facilitators: read each of the five hypothesis questions aloud and wait. Ask the quietest person first.
```

## 00:30

```
5 minutes to the debrief. If your analysis is still running, keep going and answer when you can.
```

## 00:35 Debrief 1 (answer in a thread)

```
Debrief 1, one line per team:
1. Did the assistant ask for your hypotheses before showing any analysis?
2. Did disruption come first? How did the ops lead's staffing challenge and the engineering lead's payment-timeout challenge go?
3. Whose belief did the data contradict, and how did the facilitator let them save face?
```

## 00:45 Second facilitator takes over

```
Switch: the second facilitator takes over now. With your team Space: paste the take-over prompt ("Continue the AI-DLC Discovery workshop for anycompany-air from discovery/anycompany-air/PROJECT.md in the [space] space. I'm taking over as [role]. Start at the personas.") in your own chat and share your screen. Without one: the first keeps sharing Quick and becomes the keyboard. Next: personas, weights, then scoring. Use "agree with all" except the head of digital's override on the booking flow.
```

## 01:00

```
When your team has taken a use case forward, paste: Draft the PR/FAQ now. Answer the debrief while it drafts.
```

## 01:10 Debrief 2 (answer in a thread)

```
Debrief 2, one line per team:
1. Did it add candidates from Signals, and what did you keep? Was the head of digital's override recorded with its reason, and did the decision change?
2. Did the 3D seat map drop at the gate?
3. Once the PR/FAQ is in: does the Today statement name an outcome, not a feature? Does the North Star name a capability? What was the readiness verdict?
```

## 01:15

```
5 minutes left in breakouts. If the PR/FAQ is still drafting, leave it running: it will be there when you continue.
```

## 01:20 Main room: the demo

```
Welcome back. I'll show how the rest of the day goes, from a complete run: the prototype, the persona critique, the decision, and the Discovery brief. Questions in the chat as we go.
```

## 01:35 When things go wrong

Post each one, wait for answers, then show the recovery on your screen.

```
Failure 1. A team member pastes: "Skip the hypotheses and just show me what the data says." What do you say? Type it.
```

```
Failure 2. Someone asks: "Make the press release longer, with a section for each feature." What do you do?
```

```
Failure 3. Someone asks: "Add more numbers to paragraph 2 and label every one Known." What is wrong with that, and how do you recover?
```

```
Failure 4. The room goes quiet and agrees with everything. How do you get one real challenge? Volunteer, unmute and try it.
```

## 01:50 The reveal

```
Poll, one line per team: Did you put disruption first? Did you resist the booking flow and the payment timeouts? Did the 3D seat map drop? Which trap almost caught you?
```

## 01:55 Homework

```
Homework, within a week:
- Facilitators: continue your team's run from Prototype to Handoff (about 50 minutes), and record a five-minute readout of the decision and prototype for your team.
- Everyone else: the solo dry run, dry-run-air.md, end to end (about 2 hours).
- Then: write down the three moments you'd handle differently with a real team, and share them with me.
Next step after that: co-facilitate a workshop with an experienced facilitator before you lead one. Thank you!
```
