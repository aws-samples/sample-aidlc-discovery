# Team hypotheses

Ask before any analysis, so the team's beliefs are on record before the AI's report can shape them.

## Questions

Ask one at a time, and write the answers down in the team's words:

1. What do you think is the biggest problem your customers have with the product today?
2. Who has it most?
3. Why do you think so? What have you seen or heard?
4. What else would you expect the feedback to show?
5. What would surprise you?

## Format

Turn each answer into one line the data could prove wrong:

> We expect [segment] to [problem], because [what the team has seen].

## Output

`discovery/[project]/signals/team-hypotheses.md`:

```markdown
# Team hypotheses: [product]
Written [date], before the signal analysis.

1. We expect ... because ...
2. ...

## What would surprise us
- ...
```

The Signal Analysis Report compares each hypothesis with the data in its "What the team expected" section. Do not edit this file after the analysis runs.
